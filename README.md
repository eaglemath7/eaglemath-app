# 독수리수학 학습 알림장

독수리수학 학원에서 강사가 수업 기록을 작성하고, 학생/학부모가 날짜별 알림장을 확인하는 정적 웹앱입니다.

## 주요 기능

- 관리자/부원장/강사/학생 로그인 화면
- 학생, 강사, 교시, 시간표 관리
- 오늘 수업 학생 선택 후 학습기록 작성
- 보충/개별 학생 검색 작성
- 출결, 과제수행도, 진도, 수업내용, 과제, 테스트 기록
- 학생 알림장 확인, 키워드 확인, 과제 확인
- 관리자용 기록 숨김/복구
- 브라우저 저장 데이터 JSON 백업/복원
- Supabase `app_state` 테이블을 통한 중앙 저장

## 테스트 계정

- 관리자: `admin` / `1234`
- 부원장: `deputy` / `1234`
- 강사: `kim` / `1234`
- 학생: `김민준0315` / `1234`

## 실행 방법

별도 설치 없이 `index.html`을 열면 실행됩니다.

로컬 서버로 확인하려면:

```bash
python -m http.server 4173
```

그다음 `http://localhost:4173`으로 접속합니다.

## 현재 저장 방식

현재 버전은 브라우저 `localStorage`에 먼저 저장하고, Supabase `app_state` 테이블이 있으면 같은 데이터를 Supabase에도 저장합니다.

- 같은 브라우저와 같은 기기에서는 데이터가 유지됩니다.
- Supabase 연결이 정상일 때는 다른 컴퓨터에서도 같은 데이터를 불러올 수 있습니다.
- 운영 전에는 관리자 화면의 `데이터 백업`으로 정기 백업을 권장합니다.
- 상단 상태 배지에 `Supabase 저장됨` 또는 `Supabase 연결됨`이 보이면 연결된 상태입니다.

## 보안 주의

이 정적 버전은 테스트와 데모용입니다. 비밀번호 검증 코드와 샘플 계정이 브라우저 JS에 포함되어 있으므로 실제 학생 개인정보를 장기간 운영 데이터로 넣기 전에는 서버 로그인과 데이터베이스 연결로 전환해야 합니다.
