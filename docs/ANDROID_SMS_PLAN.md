# 휴대폰 번호 단체문자 — 추가 기능 설계

상태: 사용자 요구 확인 및 기술 방식 검토. 아직 발송 기능이나 휴대폰 연결은 구현하지 않음.

사용자 선택: 안드로이드 휴대폰, 학원 웹앱에서 발송을 누르면 해당 휴대폰 번호로 자동 발송.

## 사용 흐름

1. 원장·부원장이 관리 화면에서 휴대폰 한 대를 연결한다. 휴대폰 연결 앱 설치 및 사용자의 SMS 권한 허용이 필요하다.
2. 학년·반·학생으로 필터링하고 학생 또는 보호자 번호를 선택한다. 동일 보호자 번호는 중복 제거하고 누락·잘못된 번호를 표시한다.
3. 문구 작성 후 최종 수신자 목록과 인원수를 확인하고 발송한다. 개인별 이름 치환을 지원할 수 있다.
4. 연결 앱이 서버의 승인된 발송 대기 건을 받아 개별 SMS로 전송한다. 단체 대화방은 생성하지 않는다.
5. 대기/휴대폰 처리 중/기기 발송 성공/실패/결과 불명 상태를 구분한다. 기기 발송 성공을 수신자 열람으로 표시하지 않는다.

## 필요한 구성과 검증

- 웹 관리자 UI, 관리자 전용 발송 큐·수신자 스냅샷·감사 기록·취소 API.
- 안드로이드 연결 앱: 선택한 SIM의 SmsManager, SMS 권한, 장문 분할, 발송 결과 콜백, 네트워크·백그라운드 동작.
- 기기는 짧은 유효기간의 페어링 코드로 연결하고 전용 권한으로 자기 발송 건만 처리한다. 서비스 키를 휴대폰에 넣지 않는다.
- 연결 해제·기기 분실 시 토큰 폐기. 명단 전체 조회 권한을 연결 앱에 주지 않는다.
- 전송 도중 끊긴 경우 이미 발송했을 가능성이 있으므로 결과 불명 건은 자동 재발송하지 않는다. 중복 요청은 동일 작업 ID로 처리한다.
- 통신사·요금제의 문자 과금/대량발송 제한, 실제 휴대폰 모델·안드로이드 버전, 듀얼SIM 여부를 실제 연결 전에 확인한다.
- 우선 사용자 본인 번호 소량 테스트, 화면 꺼짐/재부팅/통신 끊김/연속 클릭/한글 장문 검증 후 실사용한다.
- 연결 앱 배포 방식 결정 필요. Google Play 배포는 SMS 권한 정책 검토가 필요하며 공개 등록 가능성을 전제로 하지 않는다.

## 기존 연결 앱 활용 후보

SMSGate(https://docs.sms-gate.app/)는 Android 휴대폰 SMS 발송 API를 제공한다. 자체 연결 앱을 새로 만드는 방식만 고집하지 않고 기존 앱과 서버 중계 연동을 우선 비교한다. 공개 중계 서버 사용 시 전화번호와 메시지 처리 방식, 암호화, 기기 권한, 실제 통신사 발송 제한을 확인한 후 선택한다. 현재 후보 검토 단계이며 설치·계정 연결·문자 발송은 실행하지 않음.
