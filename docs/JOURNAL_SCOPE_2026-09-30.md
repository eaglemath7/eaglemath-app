# 알림장 기능 정리 — 2026-09-30

사용자와 합의한 알림장 운영 범위와 점검 상태를 기록한다. 인터넷 주소·도메인 관련 논의는 포함하지 않는다.

## 핵심 목표

오늘의 학습과 과제를 기록하고, 학생의 학습을 돕고, 학부모와 소통한다. 성적·랭킹보다 알림장이 우선이다. 작은 글씨와 간결한 배치로 여러 학생의 내용을 클릭을 최소화하여 확인한다.

## 일지 작성 흐름

1. 학생이 오늘 공부한 내용(교재·단원·페이지 등), 알게 된 것, 과제를 기록한다. 학생이 쓰지 못한 경우 강사가 같은 항목에 작성할 수 있다.
2. 담당 강사·관리자가 기록을 확인하고 일부 문구를 수정한다. 학생별 상태·태도 등 관찰 키워드를 추가할 수 있다.
3. 학생 원문과 직원의 수정·관찰 내용을 바탕으로 AI가 학부모용 문장을 다듬는다. 구체적인 교재·단원·페이지·과제를 유지하고 근거 없는 내용을 만들지 않는다.
4. 개별 또는 선택한 학생들의 일지를 일괄 작성하고, 검토 후 발행한다.
5. 학부모는 달력에서 날짜를 선택하여 당일 일지와 과제를 확인하고 코멘트를 남긴다. 공지도 확인할 수 있다.

학생용 기록과 학부모용 문장은 구분한다. 직원 내부 메모와 학생 전용 메시지는 학부모에게 표시하지 않는다. 교재·단원·페이지·배운 내용은 알아보기 쉽게 강조한다.

## 더블체크

- 학생 수업기록, 학생 질문·대화, 학부모 글을 한곳에서 확인한다.
- 수업기록은 연결된 알림장 발행과 담임·관리자 양쪽 확인이 필요하다.
- 질문·코멘트는 답글 또는 확인으로 처리하되, 양쪽 확인이 끝나기 전에는 확인 필요 알림을 유지한다.
- 답글 작성은 작성자의 해당 역할만 확인 처리하며 상대 역할까지 자동 완료하지 않는다.
- 관리자는 활성 원장·부원장으로 제한한다. 관리자는 담임 칸도 별도로 대리 확인할 수 있고 실제 확인자를 남긴다.
- 완료된 내용은 확인 필요 목록에서 빠져도 전체 기록으로 남긴다. 원문 변경 시 다시 확인한다.

## 현재 확인된 상태

기존 김시은 학생과 승인받은 확인용 학부모 계정으로 학생 기록 → 직원 수정 → 실제 AI 글다듬기 → 발행 → 학부모 열람·댓글 → 관리자 답글 흐름을 확인했다. 더블체크 통합, 학부모 답장 대상 분리, 학생 대화의 양쪽 확인 누락을 수정했다. 자동 테스트 16개 파일이 통과했다.

상세 근거와 남은 검증은 `RELEASE_CHECK_2026-09-30.md`에 기록한다. 모든 상황에서 완전하다는 판정은 아니다.

## 우선 보류하는 기능

- **사진 과제 제출은 현재 필수 범위에서 제외한다.** 과제는 우선 알림장에 문구로 안내하면 된다. 사진 제출 기능이나 일지와 사진 과제의 자동 연결을 알림장 완성의 필수 조건으로 삼지 않는다. 기존 기능을 삭제한다는 뜻은 아니다.
- 안드로이드 휴대폰 연동 단체문자도 보류한다.

## 알림장 범위에서 남은 검증

- 별도 담임 강사 실계정으로 담당 학생 범위와 처리 흐름 확인.
- 실제 휴대폰에서 일지 작성·열람·댓글 사용 확인.
- 여러 학생 동시 제출, 네트워크 중단·재접속, 백업 복구 확인.
- 댓글 초안은 화면 갱신·날짜 이동 시 보존하지만 브라우저 종료·새로고침까지 보존하는 것은 아직 보장하지 않음.
- 기존 학생 전원의 비밀번호 1234 통일은 실행되지 않았음. 신규 4자리 지원과 기존 계정 일괄 초기화는 구분해야 함.
