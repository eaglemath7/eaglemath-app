- 확인용 기록은 실제 수업 안내가 아니라는 문구를 포함하며 자동 삭제하지 않음.

## 이번 재점검에서 수정한 결함

1. 직원의 학부모 대화 보기에서 답장 대상이 학생으로 잡힐 수 있었음. 원본 글의 대상을 전달하고 학생/학부모 메시지와 답글을 분리하여 표시하도록 수정.
2. 더블체크 메뉴 통합이 미완료였음. 학생 수업기록·학생 질문/대화·학부모 글을 함께 모으고 기본 화면은 확인 필요, 전체 기록도 조회 가능하도록 수정.
3. 학생 질문/대화는 양쪽 확인 저장 대상에 빠져 있었음. 서버 트리거와 기존 글 이관을 추가. 답글은 작성자의 역할 한쪽만 확인하며 원문 변경 시 양쪽 재확인.
4. 더블체크에서 질문에 답글을 달면 질문함에도 답변 완료가 반영되도록 연결.

## 자동 검증

`npm run check`, `node --test tests/*.test.mjs`.

16개 테스트 파일: DB 역할·자녀별 격리, 학생/학부모 대화 분리, 강사 수정·자동 초안 연결, AI 인증·입력 보존, 보충 수업 연결, 일괄 저장 부분 실패, 공지 작성 보존, 달력 경계, HTML 이스케이프, 더블체크 유지 조건, 실제 확인자 저장, 관리자 대리 확인, 학생 질문 재확인 포함.

관리자는 활성 원장(admin)·부원장(deputy)만 해당. 담당 강사는 담당 학생 칸만 확인. 관리자는 담임 칸도 명시적으로 확인 가능하나 양쪽을 한 번에 자동 체크하지 않는다. 수업기록은 최신 원문과 연결된 일지 발행이 필수다.

## 아직 남은 항목과 운영상 제한

- 일지의 과제 문구와 사진 제출용 과제가 자동으로 동일 작업이 되지는 않음. 사진 과제는 별도 출제가 필요.
- 사진 업로드/다운로드와 사진 질문 AI의 실제 휴대폰 테스트는 미완료. 질문 AI 인증과 실패 처리만 자동 테스트 및 서버 인증 점검함.
- 별도 담당 강사 실계정 로그인 검증은 미완료. 운영 검증은 관리자 계정, 역할 차이는 DB 테스트로 확인.
- 모바일 실기기, 많은 학생의 동시 제출, 장시간 네트워크 중단·재접속, 백업 복구는 미검증.
- 댓글 작성 중 화면 재렌더·날짜 이동은 보존하지만 브라우저 종료·새로고침까지 초안을 보존하지는 않음.
- 기존 학생 전원의 비밀번호 1234 통일은 실행하지 않음. 기존 김시은은 123456으로 로그인 성공. 신규 4자리 비밀번호 지원과 전체 계정 재설정은 별개.
- 휴대폰 단체문자는 사용자 요청으로 보류. 구현·설치·발송하지 않음.
