## 아직 완료가 아닌 항목

1. 승인받은 김시은 확인용 학부모 계정을 기존 학생에 연결. 실제 로그인 → 김시은 AI 일지·수정된 과제 확인 → 댓글 작성 → 관리자 답글 → 부모 화면 답글 유지까지 검증. 관리자 계정으로 강사 확인 경로를 실행했으며 별도 강사 계정 로그인 검증과는 구분함.
2. 기존 학생 전체 비밀번호 1234 통일: 실행되지 않음. 앞선 실제 로그인에서 김시은은 123456으로 성공. 신규 계정 호환 수정이 기존 비밀번호까지 변경하지는 않음.
3. 일지의 과제 문구는 수업 안내에 보이지만 사진 제출용 homework 항목은 자동 생성되지 않음. 현재 별도 과제 출제가 필요.
4. 질문 AI의 실제 사진 첨부 → 답변 초안 생성은 이번 점검에서 미실행. 인증 수정 배포와 잘못된 토큰 차단만 운영 검증.
5. 사용자 요청으로 중1 김시연 신규 등록 성공 및 기존 학생과 구분된 정보 유지 확인. 영구 삭제는 사용자가 직접 실행했으며 에이전트는 실행하지 않음.
6. 학부모 달력과 날짜별 전체 일지, 교재·단원·페이지·배운 내용·과제의 굵은 요약, 인라인 코멘트 작성 추가. AI 문장 자체는 안전한 일반 텍스트로 유지. 달력 경계/선택 자녀·날짜/비공개 메시지 제외/이스케이프/코멘트 초안 복원 테스트 통과.
7. 모바일 실기기, 대량 동시 접속, 사진 업로드/다운로드 및 백업 복구는 이번 점검 범위에서 미검증.

## 학부모 화면 개선

- 공지를 상단에 유지하고 달력 날짜를 누르면 해당 날짜의 게시된 일지를 바로 표시.
- 학부모 작성자는 `학부모님(나)`, 직원은 이름과 실제 직책으로 구분.
- 댓글 시간은 한국 시간으로 표시. 학부모 수업 상태는 게시 여부로 표시.
- 코멘트 초안은 화면 재렌더 및 날짜 이동 때 보존하고 저장 성공 후 제거. 브라우저 종료·새로고침까지 보존하는 기능은 아님.

운영 확인: ee3f020 배포 후 학부모 v113 화면에서 공지 영역, 9월 달력, 9월 30일 김시은 AI 일지·수정 과제·코멘트·답글을 확인. 작성자 `학부모님(나)`와 `김관희 원장` 표시 확인. 29일 선택 시 빈 날짜 안내, 30일 복귀 시 코멘트 초안 유지 확인 후 페이지를 새로고침하여 미저장 테스트 문구 정리. 관리자 코멘트 목록에서 강사 확인·원장 확인 완료 및 미확인 알림 0건 확인. 운영 academy.js와 로컬 파일 SHA-256 일치.

## 필수 알림 처리 — 담임·원장 양쪽 확인

- `202609300001_required_reviews.sql` 운영 Supabase 적용 성공. 읽기 권한은 관리자 또는 배정된 강사로 제한하고 클라이언트 직접 쓰기를 금지.
- 수업기록 알림은 일지 발행 + 담임 확인 + 원장 확인 모두 충족해야 제거. 하원 승인이나 화면 열람은 확인을 대신하지 않음.
- 학부모 댓글/문의는 담임과 원장의 확인을 독립 저장. 답글은 작성자의 역할 한쪽만 자동 확인. 다른 강사에게는 확인 권한 없음.
- 한쪽이 확인해도 양쪽 화면에 나머지 확인 대기 알림 유지. 기록 삭제 없이 알림에서만 제외.
- 학생 기록/학부모 코멘트의 내용이 변경되면 양쪽 확인을 초기화. 변경 전 학생 원문이 연결된 오래된 일지 발행은 서버에서 차단.
- 기존 기록은 확인 이력을 추측해 완료 처리하지 않고 새 확인 대기로 이관.

## 관리자 담임 칸 대리 확인

- 관리자는 활성 원장(admin)·부원장(deputy)으로 한정. 두 역할은 학생 담당 배정과 무관하게 담임 칸을 명시적으로 체크 가능.
- 담당 강사는 담당 학생의 담임 칸만 확인 가능. 일반 강사·조교는 관리자 칸을 확인할 수 없음.
- 관리자 담임 체크는 관리자 칸을 자동 체크하지 않음. 서버에 실제 확인자 ID·시간을 저장하고 화면에도 확인자 이름 표시.
- 발행/답글의 자동 확인은 기존처럼 작성자의 역할 한 칸만 처리. 수업 알림장의 발행 전 확인 차단 유지.
- 활성/비활성·원장/부원장·미배정 강사·조교 권한 및 양쪽 독립 확인 테스트 포함 15개 파일 통과.
